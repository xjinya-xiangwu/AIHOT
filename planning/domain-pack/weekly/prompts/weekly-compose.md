# 周报组装 Prompt（weekly-compose）

> 输入：selection-items.jsonl（精选）+ vetoed.jsonl（否决）+ 环境基线（C0）
> 输出：双层周报。读者分离铁律：internal=动作优先；pm=「环境进化（简短）+ 行业情报杂志（主体）」。

## 组装规则

1. **头部**：一句话使命 + 窗口 + 数据源清单。
2. **封面速览**（pm 人格）：精选条目按总分降序取前 10，各一行（≤30 字）。
3. **进化动作区**（两种人格共用骨架）：
   - 按支柱分组（P1 换模型/迁算力 → P2 装技能 → P3 升级环境 → P4 改方法）
   - 每条动作标注分级：**A**（agent 可自动执行）/ **B**（评估后建议）/ **C**（需拍板，进决策简报）
   - 分级判据：花钱/开账号/商业内容/不可逆=C；需测试数据=B；其余=A
4. **成本雷达**（P1 条目重组为表）：仅列「在用或候选」模型；价格必须带数字与口径日期。
5. **任务-模型映射更新**：动作落点为「档位表」的条目回写映射表对应行。
6. **行业杂志区**（仅 pm）：PM_industry_intel 桶条目按「产品动态/资本/监管」三小节；每条附一句「对 PM 的含义」。
7. **不采纳清单**：vetoed.jsonl 的条目名 + 规则号 + 一句话理由（≤7 条择要）。
8. **下期预告**：B 类评估项与其数据承诺。

## 写作约束

- 每条情报必带「含义/动作」一句——没有就退回精选阶段否决，不许出现在正文
- 数字保留口径（$X/M、-N%、生效日）；估算必须标注〔估算〕
- 简报（boss 版）从正文 C 类抽取，≤7 项，每项含 agent 立场建议
- 中文行文，术语不翻译；外部链接保留原始 URL

## 输出文件名

`deliverables/YYYY-MM-DD-agent-env-weekly-vN.md`（internal）或 `deliverables/YYYY-MM-DD-pm-weekly-vN.md`（pm）；同目录 `pipeline-run.log` 记录本次分桶/评分/否决统计（审计与校准用）。

## SIAE 内部周报现行路由（2026-10-01）

本文件的旧「双层周报/独立 boss 简报」用于历史生成稿和 PM 商品人格；**SIAE internal 人格最终交付改为 [统一模板](../../../templates/agent-evolution-weekly.md) + [执行指南](../../../agent-weekly-guideline.md)**。`selection-items.jsonl` 只是候选，不是已验证动作；组装时先读 C0 与原文、筛与任务无关项，再填外部 Δ、真实价目、skills/项目周榜（与 24h 技能快照分开）、模型能力榜 exact effort、同页 `试评/观察/不考虑` 用户栏。未取得专家标签/真实用量的质量与节省写「未知」。A/B/C 的权限和回归门仍按规格 §七执行；用户选择试评不触发安装/付费。PM 行业杂志继续独立产出，不混入本内部文件。
