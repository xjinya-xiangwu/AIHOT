# SIAE Agent 自进化周报 · 执行指南 v1.0

> 2026-10-01 起适用。**单一事实源**：本指南 + [统一模板](templates/agent-evolution-weekly.md) 在 AIHOT fork `planning/`；[2026-10-01 合并样例](deliverables/2026-10-01-agent-evolution-weekly-merged.md)是一期证据快照，不是永远有效的榜单。Notion 页面只供人阅读/填写选择。适用阶段：A0 小闭环试验及后续周审；不把选中候选等同已安装或已发版。

## 每周按这个顺序工作

1. **先恢复项目状态，不替用户重复决策**：按 [SIAE AGENTS.md](https://github.com/xjinya-xiangwu/SIAE/blob/main/AGENTS.md) 取 `STATUS.md`、`broadcast/log.md` 与三个子仓库 HEAD；对账上周用户选择、执行回执、已装模型/skills、任务×模型用量。项目状态以 SIAE STATUS 为索引，实施版本以子仓库 HEAD/真机验证为准；冲突写明，不静默取一方。C0 缺费单时只做标价情景，不声称实际节省。
2. **采外部增量，而非搜满版面**：价格从在用通道官方 API/定价页核；能力榜记录**榜单名、采集时间、模型精确 ID、effort/fallback 和评测范围**；skills/项目先取 GitHub weekly 趋势，再核项目 README、许可、OS、密钥/外发边界。skills.sh `/trending` 的 UI 现为 **24h**，只能标日榜快照；只有连续保存七日快照才可称七日安装趋势。固定查询日期/只取最新 release 不等于「本周新变化」；按来源时间与上期快照做 diff，事件去重。
3. **一票否决与分层**：与 agent 任务无立即关联、无组件落点、原始出处不可追、许可不明却拟入包、OS/密钥/数据边界不适配者，不进动作清单；留在观察或拒收并记触发器。热门只负责发现，GitHub 星数和独立榜分不能代替真实任务收益。私人层 P、雇主/客户原文、明文凭证不得进入公开仓库或第三方试验；来源准入和人工发布门依 [产品规划 §4.0](product-plan-v1.4.md)。
4. **按目标写证据卡**：每条外部 Δ 必有原始 URL/时间、C0 相关任务、变更点、落点、建议（A/B/C）、反证/未知、预期收益的条件或区间、验证与回滚。降本看同质量的**实际费用/可采纳任务**；增效看任务完成率、人工返工/耗时与危险操作护栏；进化看此前失败的任务是否稳定通过。数字写周期、分母、过滤条件和来源。无证据时写「待测」，不把厂商宣称改写成 SIAE 成绩。
5. **一个文件，两个阅读层**：按[模板](templates/agent-evolution-weekly.md)产周报。前半给 agent 保留基线、证据、行动和负样本；§2/§3 榜单含用户可填的 `试评/观察/不考虑` 栏，§7 汇总用户所需输入。用户可直接回复 ID；留空默认观察。Agent 对每行给明确建议，但不代替用户选择。另一个 PM 行业情报商品人格不混入本内部周报。
6. **选中后仍先验证**：`试评`只入评测池。模型比较用**同一批获授权任务**、明确主指标（如事实正确或任务完成）、成本/延迟与安全护栏；约 20 条是发现明显问题的烟测，不能用于证明细微增益，正式验收须扩大且封存 held-out。新 skill 对已有原生能力先做一题同场对照，再审脚本、许可、权限、跨端兼容。先写假设、样本量判断、预算上限、止损与回滚；不经用户授权不开账号/消费/传私人数据。行为变更合入前跑相关 gold + 未参与调参的 held-out，记录前后与版本。[§4.3](product-plan-v1.4.md) 的人审发布门不因榜单热度放宽。
7. **沉淀与广播**：外部事实/拒收原因留 L0；实测可用的模型档/技能候选经批准才入 L1；真实使用与专家反馈去敏后进入 L2；坏例进入 L4 回归集。决议要写 ID、谁拍板、被否方案、原因、Owner、验收与截止。若修改 AIHOT/SIAE 仓库，先提交所属子仓库，再按 SIAE 协议更新 gitlink、`STATUS.md`、`broadcast/log.md` 顶部单条并推送；Notion 只作镜像，写后读回并记 canonical commit。未收到用户选项，不编决议；下一期首先回看上期结果。

## 最小交付检查

- [ ] 至少有真实外部 Δ；若没有，写「无可行动增量」，不凑数；所有来源有窗口、原始 URL、采集时间。
- [ ] C0 明确在用任务/版本/成本或「未知」；标价、榜分、广告宣称与实测收益分开。
- [ ] skill/项目榜与模型能力榜各有**可核口径、原位次/配置、许可或价格、适配建议、用户选择栏**；24h 不写 7d。
- [ ] 每个试评项有 Owner、假设、样本判断、质量/安全/费用止损、回滚；用户未批准前不安装/花钱/外发。
- [ ] 上期决议/动作有回执，拒收项有理由和重新上榜条件；只对本轮确实验证的内容写「完成」。
- [ ] GitHub canonical 与 Notion 入口读回一致；若改仓库，SIAE 指针、快照、广播均更新且可读。
